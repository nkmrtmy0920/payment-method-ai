# 支払い方法判定AI（無料PWA）

静的なルールベースの支払い方法判定アプリです。APIや有料AIは利用していません。

## 登録済みの決済手段
- 楽天カード
- 楽天ペイ（楽天キャッシュ払い）
- 三井住友カード（NL）
- dカード

## 登録した高還元ルール（2026年10月31日確認）
- 三井住友カード（NL）：対象コンビニ・飲食店の店頭スマホタッチ決済7％。セブン‐イレブンは必要なID連携・会員コード提示などの条件を満たすと最大10％。
- 三井住友カード（NL）：対象モバイルオーダー（マクドナルド、モスバーガー、KFC、吉野家、すき家）は7％。スターバックスは公式アプリ／App Clip経由のApple Pay決済のみ対象。
- dカード：マツモトキヨシ／ココカラファインで対象のdカード決済が3％相当。
- 楽天ペイ：公式の「ダブルで貯まる対象店舗」。楽天ポイントカードのアプリ提示と楽天ペイ残高払いを組み合わせた最大2.5％（条件あり）。
- 既存ルール：ロピア、叙々苑など。

## 重要な注意
モバイルオーダーは店頭と対象店舗・支払条件が異なるため、入力欄で選択を分けています。楽天ペイの最大2.5％プログラムは店頭のコード・QR・セルフ払いが対象で、ネット決済・アプリ注文は対象外です。

dカードの特約店にはオンライン・旅行・専用プリペイドカード経由など、店頭の通常カード払いと異なる条件のものがあります。そうした決済手段を追加で持つことを前提にしたルールは、今回の判定には含めていません。また、過去のノジマ割引やスターバックス カードのdカード特約店ポイントなど、終了した特典は含めていません。

## 公開方法
GitHub Pagesのリポジトリ直下にある `index.html` と `sw.js` を置き換えてください。既存の `manifest.webmanifest` と `icon.svg` はそのままで利用できます。

## 注意
還元率・対象店舗・決済方法は変更されます。アプリは最新情報を自動取得しないため、会計前に各社公式ページで確認してください。
